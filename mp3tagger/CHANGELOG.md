# Changelog

## 0.1.0

First release.

- Browse folders, edit tags of one or many files (`<keep>` for differing values), ID3v1/v2.3/v2.4
- Cover art: view, add, replace, extract, remove; move to or embed from a `cover.jpg` in the folder
- Filename → Tag, Tag → Filename (also sorting into folders), Tag → Tag, auto-numbering
- Change case, find and replace (with regular expressions)
- MusicBrainz lookup from the CD identifier (MCDI) or by name; covers from the Cover Art Archive or iTunes
- Runs as a Home Assistant app (ingress) and as a standalone Docker image
